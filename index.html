About DFS Algorithm
1. Depth First Search & Stack
DFS traverses as deep as possible along each branch before backtracking. It utilizes a LIFO (Last-In, First-Out) stack. In this visualizer, the yellow line displays the active stack from start to current node.
2. Dead Ends & Backtracking
When DFS reaches a cell with no unvisited traversable neighbours, it marks that cell as a dead end (red) and pops it from the stack, backtracking to the previous parent cell to explore alternate branches.
3. Is DFS Optimal (Shortest)?
No. DFS is not guaranteed to find the shortest path. It commits deeply to whichever branch matches its neighbour priority order first. In a tree maze (no cycles), only one path exists, but in a cyclic maze, DFS may take a convoluted path.
4. 4-Bit Maze Wall Encoding
Walls are encoded via 4 bit flags: WALL_N = 0x1 (North), WALL_E = 0x2 (East), WALL_S = 0x4 (South), WALL_W = 0x8 (West). The 13×13 matrix defines shared corridor walls with open boundary exits at (0, 6) and (12, 6).
